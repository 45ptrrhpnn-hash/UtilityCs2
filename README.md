# UtilityCS2 - Ready-to-deploy prototype

**Project:** UtilityCS2
**Theme:** Dark blue + orange accents (CS2 style)
**Purpose:** Lineups de granadas de pros atuais — protótipo pronto para deploy no Vercel.

## Conteúdo incluído
- Código Next.js + Tailwind (skeleton)
- Componentes: LineupCard, FilterBar, Favorites
- 3 lineups de exemplo com vídeos placeholders (substitui por mp4 reais)
- Instruções para deploy no Vercel

## Como usar
1. Cria um repo novo no GitHub (`utilitycs2`).
2. Faz upload deste ficheiro .zip e extrai para o repo.
3. Liga o repo ao Vercel (Import Project -> GitHub).
4. No Vercel, define `NODE_VERSION` se necessário e deploy.

## Notas
- Os ficheiros `public/exemplo-videos/*.mp4` são placeholders: substitui por vídeos reais.
- Para puxar dados reais dos pros (HLTV), é preciso um scraper / API e respetiva autorização.
